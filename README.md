# Portafolio Personal

**Estudiante:** Robinson Eduardo Suárez Luna

## Descripción
Este proyecto es un portafolio personal desarrollado para la asignatura Programación de Sistemas Web. Presenta información sobre el estudiante, sus habilidades, proyectos y una sección de contacto.

## Tecnologías utilizadas
- HTML5
- CSS3
- Git y GitHub

## Contenido del portafolio
- Inicio
- Sobre mí
- Habilidades
- Proyectos
- Contacto

## Instrucciones para visualizar
1. Descargar o clonar este repositorio.
2. Abrir el archivo `index.html` en un navegador web.
